# 👗 Style Finder – AI-Powered Fashion Understanding & Recommendation

An intelligent system that analyzes clothing images and finds visually similar styles using state-of-the-art multimodal AI models.

---

## 🚀 Overview

Choosing outfits or finding similar styles online can be difficult and time-consuming.
**Style Finder** solves this by allowing users to upload an image and instantly:

* 🔍 Identify clothing style
* 🎯 Find similar fashion items
* 🧠 Understand visual features using AI

---

## 🧠 How It Works

The system combines **computer vision + vector search + vision-language models**:

1. 📷 User uploads an image
2. 🧬 Image is encoded using **CLIP embeddings**
3. 🔎 Similar items are retrieved using **FAISS similarity search**
4. 🤖 A vision-language model (**Qwen2-VL**) generates descriptions

---

## 🛠️ Tech Stack

* Python
* CLIP (OpenAI)
* FAISS (Facebook AI Similarity Search)
* Qwen2-VL (Vision-Language Model)
* Gradio (UI interface)

---

## ✨ Features

* 🔍 Image-based fashion search
* 🧠 Multimodal understanding (image + text)
* ⚡ Fast similarity retrieval using FAISS
* 🎨 Interactive UI with Gradio
* 📈 Scalable architecture for large datasets
